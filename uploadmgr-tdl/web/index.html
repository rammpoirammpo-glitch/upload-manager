tdl — Telegram Downloader

This app is a headless command-line tool. It has no web dashboard; this page only confirms the container is running. Use tdl from the terminal on your umbrelOS device with docker exec:

docker exec -it uploadmgr-tdl_server_1 tdl login
docker exec -it uploadmgr-tdl_server_1 tdl up --path /data/file

Persistent data (login session, config, downloads) lives under this app's data directory at /data.
